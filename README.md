# AI Stock Selection Dashboard

AI-driven stock selection and observation dashboard for Stanley.

## UX Prototype v0.1

- 16:9 desktop-first dashboard, responsive for iPad
- Light, low-fatigue visual theme
- AI Observation Lists by six investment horizons
- AI recommendation score, target price, confidence and change tracking
- AI Selection Flow exposed in the left navigation
- Individual stock analysis remains a separate navigation page
- Portfolio input page for purchased stocks
- GitHub stores application assets/configuration; production data is intended for the connected data layer

> This repository is a public frontend prototype. Authentication/data protection must be enforced by the production Supabase layer before operational use.
